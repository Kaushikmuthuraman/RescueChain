# RescueChain

A full-stack disaster rescue coordination platform with blockchain-backed audit trails.

## Architecture Overview

### Frontend
- **Framework**: React + Vite
- **UI Style**: Government-style, clean and professional interface
- Located in `frontend/` directory

### Backend
- **Runtime**: Node.js
- **Framework**: Express (REST API)
- Located in `backend/` directory

### Database
- **Type**: PostgreSQL
- **Management**: pgAdmin 4
- Scripts and schemas located in `database/` directory

## Key Features

- **Victim Authentication**: Demo OTP system for quick access
- **Organization Authentication**: Credential-based login for NGO, DDMA, and SDMA
- **Unified Payment**: Single common UPI QR code for all transactions
- **Accountability**: Photo-backed verification for rescue operations
- **Audit Trail**: Polygon blockchain integration for immutable audit hashes
- **Data Management**: Support for both seeded demo data and live production data
